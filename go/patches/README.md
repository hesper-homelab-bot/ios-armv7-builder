# armv7/iOS Go 1.27.2 port patches

Every divergence from upstream go1.27.2 that is load-bearing for the
darwin/arm revived port.  Numbered patches apply (`patch -p1`) to a
pristine go1.27.2 source tree; they were generated by diffing this tree
against the official go1.27.2 sources on 2026-11-19.

Background: Go upstream dropped darwin/arm (32-bit iOS) after Go 1.14.
The port revives it inside the Go 1.27.2 tree, with an internal-linking
Mach-O writer, a pure-Go runtime (no cgo), and a per-thread g-slot table.
Evidence chains live in ../docs/tailcat-porting.md (sections 八/九) and in
go-port's git log (~/scratch/go-port/go, commits 4ede5256..HEAD).

## Numbered patches

- 010-runtime-darwin-arm.patch — runtime: the revived darwin/arm support.
  Trampolines rewritten from the arm64 originals with three live-caught
  transcription bugs fixed (syscallN_trampoline reserve ×4 not ×2, result
  writebacks present, n<=4 copy-loop guard); TLSG_IS_SLOT_TAB per-thread
  g-slot table keyed by TPIDRURO (save_g/load_g with LDREX/STREX claim);
  sigtramp loads g unconditionally (the iscgo guard is wrong for a pure-Go
  port); nanotime1 + vlrt div helpers nosplit (throwsplit-window crashes);
  preemptMSupported=false (async-preemption SIGURG hangs threads whose TLS
  g-slot is uninitialized); badsignal drops signals arriving on foreign
  (libpthread workqueue) threads; rt0/arm+os/signal_darwin_arm glue;
  pprof defs.

- 020-syscall-darwin-arm.patch — syscall: the zsys darwin/arm set (1.14
  generation, regenerated for 1.27), the 1.14 SVC Syscall/Syscall6/9
  assembly, and two 64-bit-argument-slot fixes in the generated bodies:
  Seek splits the int64 offset lo/hi into separate slots (arm64-copied
  code truncated it, whence landed on the kernel's high-offset slot ->
  EINVAL on every os.File.Seek), and mmap passes pos as two slots via
  syscall9 (off_t is the 6th argument, two slots on arm32).

- 030-cmd-link-darwin-arm.patch — cmd/link: internal-linking Mach-O
  support for darwin/arm.  arm/asm.go: MACHO BL relocations bake the PLT
  index into imm24, R_ADDR rebase/bind emission for PIE; arm/obj.go;
  ld/macho.go: __plt section (self-contained stubs, no S_SYMBOL_STUBS —
  the stub-stride/indirect semantics poison iOS 10 dyld), synthetic
  .pltstub symtab entries, LC_DYLD_INFO bind/rebase tables, __DWARF
  segment given a real vsize and its own address range (iOS 10 dyld
  rejects filesize > vmsize); ld/sym.go: LinkEditPLT/GOT plumbing.

- 040-cmd-vendor-xsys-darwin-arm.patch — cmd/vendor: x/sys darwin/arm
  file set copied from the xsys-v048 port (same version; arm64 files
  verified byte-identical).  Required to build the toolchain itself
  (Flock_t in cmd/vendor/golang.org/x/sys/unix/fcntl_darwin.go).

- 050-crypto-x509-pem.patch — crypto/x509: PEM-only root path for
  darwin/arm (/etc/ssl/cert.pem).  The macOS default walks
  /System/Library/... framework bundles and iOS 10 dyld refuses the
  resulting LC_LOAD_DYLD shapes.

- 060-internal-platform-hooks.patch — internal: platform/supported.go +
  zosarch gain darwin/arm; internal/syscall/unix/net_darwin.go retagged
  (its cgo_import_dynamic of libresolv made the linker emit an
  LC_LOAD_DYLD for a dylib iOS 10 does not have) with the syscall hooks
  split out (syscall_syscall* linkname + AI_* constants); std vendor
  gains x/sys cpu_darwin_arm.go (wireguard-go checksum needs IsBigEndian).

## Deliberately NOT in the patches

Generated files (zbootstrap.go, zdefaultcc.go, zversion.go,
time/tzdata/zzipdata.go) are produced by make.bash at build time.
test/ and pkg/ are untouched.
